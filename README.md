**/Chrono-Insight/code** <br>
  -> Contains code files for the whole dashboard. <br>
  -> requirements.txt - contains all the libraries for the code to run, run_after_requirements.txt - contains bash command to download NLP model. <br>
  -> main.py - Python Dash code for the dashboard UI and dashboard functionality. <br>
  -> nlp_pipeline.py - NLP model code for analyzing PDF files and creating structured data. <br>
  -> user_sessions (dir) - directory to hold session wise pdf analysis. <br>
  -> default_data (di) - directory holding the dataset for default visualizations. <br>

**/Chrono-Insight/documents** <br>
  -> Contains our project related documents. <br>
  -> Project Charter, Final Report and . <br>

**/Chrono-Insight/source data** <br>
  -> Contains all the PDF files used for our dataset creation along with their citations. <br>
